# 搜索结果参数展示与临时板料型号设计

## 目标

1. 删除板料规格、图纸、成品、板料、余料页面的自选字段升降序功能。
2. 列表始终保留型号、名称、数量、状态等基础信息，并在搜索后明确展示实际使用的筛选参数和值。
3. 允许未选择已有规格而入库的临时板料后续补填型号，且不改变原有材质、尺寸、数量和流水。
4. 已撤回且库存为零的临时板料不再占用当前库存列表，但历史流水继续保留。
5. 保持桌面端和移动端不需要横向滚动。

## 列表展示方案

采用“固定基础信息 + 自适应参数摘要”，不为每个可搜索参数增加独立表格列。

### 固定基础信息

- 图纸：编号、名称、版本、状态、操作。
- 成品：型号、名称、库存数量、库位、操作。
- 板料：型号、材质、库存数量、库位、操作。
- 余料：型号、库存数量、库位、操作。
- 板料规格：型号、材质、状态、操作。

各页面在固定信息之外保留一个紧凑的“参数信息”区域。桌面端作为一列显示，窄屏下作为记录内部的一组标签和值显示。

### 参数信息排序

1. 没有搜索条件时，显示该模块最常用的关键参数。
2. 使用具名参数筛选后，本次参与筛选的非空参数排在参数信息最前，并使用统一的轻量强调样式。
3. 使用多个参数筛选时，按搜索表单中的顺序显示全部筛选参数。
4. 搜索参数之后继续显示未重复的关键参数，确保用户仍能判断记录的主要属性。
5. 参数值来自当前结果记录本身，不直接回显用户输入，避免模糊匹配时显示错误值。
6. 普通关键词搜索时，检测该记录实际命中的型号、名称、分类、材质、备注等字段，并在参数信息中显示命中的字段和值；没有可确定的字段时只保留默认关键参数。

示例：成品按“厚度 3、材质 65Mn”筛选后，固定区域继续显示型号、名称和库存数量，参数信息首先显示“总成品厚度 3”“材质 65Mn”，然后显示钢板厚度等默认关键参数。

### 各模块默认关键参数

- 图纸：总成品厚度、钢板厚度、材质、齿数、模数。
- 成品：总成品厚度、钢板厚度、材质、产品分类。
- 板料：长、宽、厚度、材质。
- 余料：长、宽、厚度、材质。
- 板料规格：长、宽、厚度、密度。

单条记录只展示适量内容；缺失值不占位，重复参数不重复显示。完整信息仍通过“明细”查看。

## 排序功能调整

- 从板料规格、图纸、成品、板料、余料页面删除自选排序字段和升降序控件。
- 页面和导出链接不再传递自选排序参数。
- 服务端保留确定性的默认自然排序，型号按字母和数字组合顺序排列；同型号记录再按现有业务次序排列。
- 旧书签中残留的排序查询参数可以被忽略，不能导致页面报错。

## 临时板料型号

### 数据归属

板料库存批次增加可空的型号字段。该字段记录用户为该批板料补填的业务型号，不强制关联已有板料规格，也不改变原始尺寸字段。

显示优先级为：

1. 批次已补填的型号；
2. 入库时明确选择并保存的已有规格型号；
3. 旧数据能够按材质、长、宽、厚度精确匹配到的规格型号；
4. “临时规格”。

为避免后续规格变化影响历史批次，入库批次保存自己的型号文本；已有规格仍用于入库时快速填写参数，不作为批次显示名称的唯一来源。

### 补填规则

- 当前仍有库存的临时板料显示“补填型号”操作。
- 用户输入型号并确认后，只更新该库存批次的型号。
- 材质、长、宽、厚度、密度、数量、库位、操作员和历史流水全部保持不变。
- 型号不能为空，去除首尾空格后保存；允许字母、数字及现有型号常用符号。
- 已有相同型号时允许补填，因为不同批次可以属于同一型号；库存汇总按型号及现行业务规格维度归组。

### 撤回和零库存

- 撤回入库继续通过反向流水处理，不删除原库存批次和历史交易。
- 当前库存页只展示数量大于零的板料批次或汇总组。
- 数量为零的临时板料不再显示在当前库存中，也不再提供补填型号入口。
- 流水页仍显示原入库、撤回流水、时间、数量和操作员，保证可追溯。

## 数据流

1. 搜索表单解析具名参数和普通关键词。
2. 查询服务返回结果，同时页面层根据当前筛选条件生成每条记录的参数摘要。
3. 模板渲染固定基础信息和参数摘要，不通过增加大量列展示筛选结果。
4. 板料入库时若选择已有规格，将规格型号文本写入库存批次；手工录入时型号可以为空。
5. 临时板料补填型号通过独立操作更新批次型号，并记录修改时间和操作员审计信息（沿用现有审计机制）。

## 错误处理

- 补填不存在、空白或过长的型号时返回表单错误，不修改库存数据。
- 已不存在或已为零库存的批次提交补填请求时返回明确提示并刷新当前库存页。
- 搜索参数格式无效时沿用现有校验；参数摘要只使用成功解析并参与查询的条件。
- 数据库升级采用项目现有的运行时迁移方式，重复执行必须安全。

## 测试与验收

- 五类页面均不再出现自选字段升降序控件。
- 旧排序参数不会导致页面错误，结果使用默认自然排序。
- 未搜索时显示固定基础信息和默认关键参数。
- 单参数、多参数及普通关键词搜索后，结果显示真实命中参数和值，且基础信息不被替换。
- 参数信息无重复项，空值不显示。
- 临时板料可补填型号，补填前后材质、尺寸、数量及流水不变。
- 相同型号的不同批次可正常归组并查看明细。
- 撤回入库后，零库存临时板料从当前库存消失，流水仍可查询。
- 桌面和窄屏页面均无整页横向滚动，操作按钮始终可见。
- 现有库存、图纸搜索、导出和撤回测试保持通过。

## 非目标

- 本次不新增任意字段排序的替代入口。
- 本次不自动把手工型号创建为板料规格主数据。
- 本次不删除零库存批次或历史流水。
- 本次不改变图纸、成品、板料和余料的库存计量规则。
