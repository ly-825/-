# 纸材全局厚度优先排序设计

## 目标

纸圈和纸张混合显示时，所有纸材规格与库存相关页面都先按厚度数值升序排列，不再先把纸圈和纸张分组。

## 统一排序规则

纸材规格、纸材入库规格下拉、纸材库存汇总、纸材出库可用规格及纸材库存 Excel 统一使用以下升序键：

1. 厚度数值。
2. 纸材类型：相同厚度时纸圈在前、纸张在后。
3. 对应尺寸：纸圈依次按内径、外径；纸张依次按长度、宽度。
4. 型号自然顺序。
5. 纸材名称/材质自然顺序，作为规格完全相同时的稳定排序键。

纸材规格维护页继续把启用规格放在停用规格之前；每个状态组内部执行上述统一顺序。

## 实现方式

修改纸材公共排序键，使厚度位于纸材类型之前。库存分组使用相同字段顺序。各页面和库存导出继续调用公共排序逻辑，不分别增加页面级排序代码。

纸材流水和纸材明细不改为尺寸排序：流水保持按创建时间从新到旧，明细批次保持按入库时间从旧到新，以保留流水查看和 FIFO 业务语义。

## 测试与验收

- `0.5` 厚纸张排在 `2.0` 厚纸圈之前。
- 同厚度时纸圈排在纸张之前。
- 同为纸圈时依次按内径、外径排序。
- 同为纸张时依次按长度、宽度排序。
- 规格页、入库下拉、库存汇总、出库可用规格和库存 Excel 的顺序一致。
- 纸材流水仍按时间倒序。

## 数据影响

不修改数据库结构和库存数据，只调整查询结果渲染与导出时的排序顺序。
