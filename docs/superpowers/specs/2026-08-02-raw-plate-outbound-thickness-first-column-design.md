# 板材出库厚度列前置设计

## 目标

调整板材出库页面“当前可用规格”表格的列顺序，让用户先看到最常用的厚度字段。

## 显示规则

表格列顺序由：

`材质 → 长度 → 宽度 → 厚度 → 可出库总块数 → 批次数 → 库位 → 操作`

调整为：

`厚度 → 长度 → 宽度 → 材质 → 可出库总块数 → 批次数 → 库位 → 操作`

即厚度和材质交换位置，其余列保持不变。

## 范围

- 只调整板材出库“当前可用规格”表格的表头和数据单元格顺序。
- 上方搜索栏已经以厚度为第一项，保持不变。
- 下方确认出库表单保持不变。
- 板材排序仍按厚度、宽度、长度升序，不修改库存或 FIFO 逻辑。

## 测试与验收

- 表头以“厚mm”开头，材质位于宽度之后。
- 每行第一个数据单元格显示厚度，第四个显示材质。
- “当前可用规格”仍位于“确认出库”上方。
- 现有板材出库和排序测试保持通过。

## 数据影响

不修改数据库结构和库存数据，仅改变页面列的显示顺序。
