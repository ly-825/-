# 纸材按类型与型号排序设计

## 目标

纸材规格、纸材入库选择、纸材库存和纸材出库统一使用同一套排序规则，不再以厚度、内外径或长宽作为主要排序条件。

## 排序规则

1. 先按纸材类型分组：纸圈在前，纸张在后。
2. 同一类型内按型号进行自然排序，数字按数值大小比较，而不是按普通字符串逐字比较。
3. 纸圈型号示例顺序：`3960.02`、`3969.01`、`3970.01`、`TNX148.2A`、`TNX236.2A`。
4. 纸张型号示例顺序：`200×300×0.5`、`400×400×0.5`、`400×600×0.5`。
5. 型号完全相同时，依次使用纸材名称/材质、厚度和尺寸作为稳定的后备排序字段。

## 影响范围

- 纸材规格列表。
- 纸材入库页面的规格下拉选项。
- 纸材库存汇总列表。
- 纸材出库页面的可用规格列表。
- 纸材库存 Excel 导出顺序（复用库存汇总排序结果）。

纸材流水按发生时间倒序展示，不改为型号排序。

## 实现方式

集中修改纸材规格与纸材库存分组的排序键，所有使用这些公共排序函数的页面自动保持一致。保留自然排序函数，避免 `TNX10` 排在 `TNX2` 前面。

## 验收标准

- 纸圈始终排在纸张之前。
- 每个类型内部以型号自然升序排列。
- 改变厚度或尺寸不会把型号顺序打乱。
- 规格、入库、库存、出库和库存导出的顺序一致。
- 纸材流水仍按最新记录优先。
- 现有库存数量、单价、出入库和汇总分组规则不发生变化。

## 测试

- 更新规格排序测试，覆盖纸圈和纸张混合数据。
- 更新库存汇总排序测试，证明型号优先于厚度和尺寸。
- 验证入库选项、库存页面、出库页面和库存导出的顺序。
- 运行完整纸材管理与导出测试。
