# 纸材规格隐藏字段空值修复设计

## 问题

纸圈规格表单会隐藏纸张的长度和宽度字段，但隐藏字段仍以空字符串提交。FastAPI 在进入业务函数前尝试将空字符串解析为可选浮点数，导致创建或修改纸圈规格时返回 422。

纸张模式存在对称风险：纸圈的内径、外径字段也可能以空字符串提交。

## 修复方案

采用前后端双层防护：

1. 表单切换纸材类型时，隐藏字段同时设置为 `disabled`，让浏览器不提交当前类型无关的字段；显示字段恢复启用并按现有规则设为必填。
2. 创建和修改接口把四个可选尺寸字段作为字符串接收，将空字符串统一转换为 `None`，非空内容转换为浮点数后再交给现有规格校验逻辑。
3. 非数字内容返回明确的 422 表单校验错误；纸圈仍校验型号、内外径及外径大于内径，纸张仍校验长度和宽度。

## 测试范围

- 纸圈提交空长度和空宽度，可以成功保存。
- 纸张提交空内径和空外径，可以成功保存并自动生成型号。
- 页面脚本会禁用当前类型的无关字段。
- 现有纸材管理测试全部保持通过。

## 数据影响

不修改数据库结构，不迁移历史数据，只修正表单提交和接口参数规范化行为。
