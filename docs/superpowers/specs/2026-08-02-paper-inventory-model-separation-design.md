# 纸材库存按型号分开汇总设计

## 问题

纸材规格中的 `3969.01`、`3960.02`、`3970.01` 是三条独立规格，也分别完成了入库，但库存汇总错误地把它们合成一行，数量、单价范围和批次数也随之混在一起。

## 期望行为

- 不同纸材规格必须始终显示为不同库存行，即使类型、材质和厚度相同。
- 同一纸材规格的多次入库仍汇总为一行。
- 同一行汇总该规格的库存数量、有效库存批次数、库位和单价范围。
- 库存页、出库可用规格和库存 Excel 导出使用完全相同的分组规则。
- 原有厚度优先排序保持不变。

## 设计

纸材库存的分组边界采用：

1. `specification_id` 作为主标识，区分独立创建的纸材规格。
2. 入库批次保存的型号、类型、材质、厚度和尺寸快照共同参与分组，防止历史规格修改后把不同快照错误合并。

将该规则集中为唯一的库存分组键函数，库存页、出库页和 Excel 导出继续统一调用 `paper_inventory_groups`，避免各页面自行实现不同的合并逻辑。

## 数据处理

不修改现有入库批次和流水数据。修复只调整读取和汇总逻辑，因此重新打开库存页面后即可按正确型号分行，不需要重新入库。

## 测试

- 三个相同材质、相同厚度但型号和规格 ID 不同的纸圈，必须生成三条库存汇总。
- 同一规格 ID、同一型号的多个有效批次，必须汇总为一条，并正确累计数量、批次数和单价范围。
- 库存页面必须同时显示三个独立型号，且每个“查看明细”链接指向对应规格 ID。
- 运行纸材模块测试和完整测试套件，确认排序、出库、导出和其他库存功能未回归。
