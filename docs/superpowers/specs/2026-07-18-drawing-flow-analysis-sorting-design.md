# 图纸动态参数、产品出入库分析与列表排序设计

## 目标

在不增加页面横向滚动的前提下，完成以下改造：

1. 已确认图纸按具体参数搜索后，在原“状态”列显示匹配图纸的实际参数。
2. 将“产品出库分析”扩展为可切换的“产品出入库分析”，并将逐单明细移到查询区下方。
3. 为板料规格、已确认图纸、成品库存、板料库存和余料库存增加按自选参数升序或降序排列的功能。

## 范围

### 包含

- 已确认图纸页的动态筛选参数列。
- 产品出入库分析的页面、统计服务和 Excel 导出。
- 五个常用汇总列表的服务端排序。
- 桌面端与手机端的响应式检查。

### 不包含

- 库存流水和逐单明细的任意字段排序。这些记录仍默认按时间倒序。
- 修改库存计算、FIFO 扣减或历史流水数据。
- 新增数据库表或数据迁移。

## 已确认图纸动态参数列

### 显示规则

- 列表总列数保持六列，不新增表格列。
- 当未使用具体图纸参数筛选时，原列标题为“状态”，单元格继续显示“已确认”。
- 当使用一个或多个具体参数筛选时，列标题改为“筛选参数”。
- 每行显示该图纸的实际参数值，而不是简单回显搜索词。
- 多参数时在同一单元格内分行显示，例如“压力角 30°”和“模数 2”。
- 普通文本筛选（型号、名称、分类、材质）不触发动态参数列。

### 参数显示映射

- 总成品厚度：`product_thickness`
- 钢板厚度：`plate_thickness`
- 外径：`max_outer_diameter`
- 内径：`min_inner_diameter`
- 齿数：优先组合 `tooth_type` 与 `teeth_count_text`，兼容普通数字齿数
- 模数：优先使用 `module_text`，兼容数值模数
- 压力角：`pressure_angle`
- 公法线：优先使用 `common_normal_length_text`，兼容数值
- 量棒直径：`pin_diameter`
- 跨棒距：`pin_span`

## 产品出入库分析

### 路由与切换

- 保留现有 `/admin/reports/product-outbound` 路由，避免旧书签和导航失效。
- 新增 `flow_type=in|out` 查询参数，默认为 `out`，保持旧页面的默认行为。
- 页面标题和导航文案改为“产品出入库分析”。
- 使用分段切换控件选择“入库”或“出库”，切换后保留可共用的型号和时间条件。

### 查询与口径

- 入库模式查询成品 `transaction_type=in` 流水。
- 出库模式查询成品 `transaction_type=out` 流水，保留客户和用途筛选及现有销售口径。
- 两种模式都排除已撤回流水，并仅统计 `inventory_type=product` 的记录。
- 入库模式只显示型号和时间筛选，隐藏不适用的客户和用途筛选。

### 页面顺序

1. 页面标题和操作按钮
2. 入库 / 出库切换与查询条件
3. 当前模式的逐单明细
4. 当前模式的统计卡片
5. 出库模式的备货建议（入库模式不显示）
6. 当前模式的月度汇总

### 汇总与导出

- 入库统计显示入库总量、入库次数、涉及型号数和月均入库量。
- 出库统计保留销售出库量、总出库量、出库次数和客户数。
- 逐单明细默认按时间倒序，不加自由排序。
- Excel 导出携带 `flow_type`，导出内容与当前模式和筛选条件一致。

## 列表自选排序

### 交互

- 每个目标页在现有筛选区或列表上方增加“排序参数”下拉和“升序 / 降序”分段控件。
- 排序参数使用 `sort_by`，方向使用 `sort_dir=asc|desc`。
- 排序与现有筛选条件一起提交，刷新和复制链接后仍保持。
- 每个页面只允许白名单字段，非法值回退到该页默认排序，不将查询参数直接传入 SQL 排序。
- 型号和名称使用自然排序，保证 `TNX2` 在 `TNX10` 前面。
- 长度、宽度、厚度、数量等字段按数值排序，空值统一放在末尾。

### 页面与排序白名单

- 板料规格：规格名称、材质、长度、宽度、厚度、密度、状态、创建时间。
- 已确认图纸：产品编号、产品名称、分类、材质、总成品厚度、钢板厚度、外径、内径、齿数、模数、压力角、更新时间。
- 成品库存：产品编号、材质、总成品厚度、钢板厚度、库存数量、批次数、最近更新时间。
- 板料库存：材质、长度、宽度、厚度、库存数量、批次数、最近更新时间。
- 余料库存：材质、厚度、直径 / 可用尺寸、库存数量、批次数、最近更新时间。

## 实现边界

- 排序字段定义为每个页面的明确白名单和取值函数，避免将页面逻辑与 SQL 字符串拼接。
- 库存页先按现有规则汇总同型号 / 同规格数据，再对汇总行排序，不改变分组与数量计算。
- 导出链接对已支持导出的列表传递当前 `sort_by` 和 `sort_dir`，保持页面与 Excel 顺序一致。
- 保留现有默认排序，只在用户明确选择排序参数后改变顺序。

## 响应式与可用性

- 不增加任何目标表格的列数。
- 查询、切换和排序控件在宽度不足时自动换行。
- 动态参数单元格允许换行，不撑宽表格。
- 已确认图纸继续使用紧凑列表及手机端纵向记录布局。
- 桌面端 1366px 和手机端 390px 下，`document.documentElement.scrollWidth` 必须等于 `clientWidth`。

## 错误处理

- 非法的 `flow_type`、`sort_by` 或 `sort_dir` 不报 500，而是回退到安全默认值。
- 日期格式错误继续返回现有的明确提示。
- 无匹配数据时保留空状态，不隐藏查询和排序控件。

## 测试与验收

### 自动测试

- 单一参数搜索显示对应实际参数，且不再显示“状态”列标题。
- 多参数搜索在同一列显示所有参数。
- 仅使用普通文本筛选时仍显示“状态 / 已确认”。
- 入库与出库切换只统计对应类型的成品流水，并排除撤回记录。
- 入库页面不显示客户 / 用途筛选和备货建议。
- 逐单明细在 HTML 中位于统计卡片、备货建议和月度汇总之前。
- 五个目标列表对数字、文本和型号排序都有升序、降序覆盖。
- 非法排序参数使用默认顺序。
- 导出模式与页面出入库模式一致。

### 浏览器验收

- 在 1366×768 与 390×844 视口检查五个排序页、已确认图纸参数搜索、入库分析和出库分析。
- 确认页面没有横向滚动，操作按钮可见，文本不重叠，切换与排序能保留查询状态。
