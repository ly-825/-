# 杭州特耐时移动库存设计系统

> 页面开发前先读取 `pages/` 下对应页面规范；页面规范只覆盖特殊布局，颜色、字号、触控和反馈仍以本文件为准。

## 1. 设计方向

- 风格：工业化、克制、数据优先、触控优先。
- 目标：员工在厂房环境中能快速看清型号、尺寸、数量、库位和操作状态，单手完成查询与出入库。
- 视觉：浅色底、白色内容面、深石板导航、绿色主操作；层级依靠字号、留白、边框和少量阴影建立。
- 禁止：玻璃拟态、霓虹、装饰性渐变、大面积插画、无意义动画、桌面宽表格横向压缩、仅靠颜色表达状态。
- 默认使用浅色主题；颜色全部语义化，为后续暗色主题预留变量，但首轮不增加暗色模式的实现与验收成本。

## 2. 颜色

| 语义 | 颜色 | 用途 |
| --- | --- | --- |
| `primary` | `#334155` | 顶部栏、选中导航、重要标题 |
| `primary-pressed` | `#1E293B` | 主导航按下态 |
| `accent` | `#059669` | 每屏唯一主操作、成功状态 |
| `accent-pressed` | `#047857` | 主操作按下态 |
| `background` | `#F8FAFC` | 页面底色 |
| `surface` | `#FFFFFF` | 卡片、表单、弹层 |
| `surface-muted` | `#F1F5F9` | 筛选区、只读区、次级块 |
| `text-primary` | `#0F172A` | 主要信息 |
| `text-secondary` | `#475569` | 说明、标签 |
| `text-tertiary` | `#64748B` | 次要提示；不可用于过小正文 |
| `border` | `#E2E8F0` | 卡片和输入框边界 |
| `warning` | `#B45309` | 待确认、低库存、风险提示 |
| `warning-bg` | `#FFF7ED` | 警示背景 |
| `danger` | `#DC2626` | 撤回、停用、失败 |
| `danger-bg` | `#FEF2F2` | 危险提示背景 |
| `info` | `#2563EB` | 连接、同步、普通信息 |

规则：正文对比度不低于 4.5:1；成功、警告、危险必须同时显示文字或图标，不允许只有颜色。

## 3. 字体与数字

- 中文优先：`Noto Sans SC`, `PingFang SC`, `Microsoft YaHei`, sans-serif。
- 小程序不依赖在线字体下载，优先系统字体；设计稿统一按 Noto Sans SC 度量。
- 页面标题：44rpx / 700；区块标题：34rpx / 600；卡片标题：30rpx / 600。
- 正文和输入：30rpx / 400；辅助文字：26rpx / 400；状态标签：24rpx / 500。
- 数量、金额、日期、厚度、尺寸、型号使用 `font-variant-numeric: tabular-nums`。
- 关键库存数量不小于 36rpx；单位紧随数值但降低一级字重。
- 型号、尺寸默认完整换行，禁止拆成逐字竖排；只有已提供“查看完整内容”的位置才可省略。

## 4. 网格、留白与安全区

- 基于 8rpx 基础网格；常用间距：8 / 16 / 24 / 32 / 48rpx。
- 页面左右边距 32rpx；卡片内边距 28rpx；卡片间距 20rpx；表单字段间距 24rpx。
- 所有点击区域最小 88×88rpx，点击目标之间至少 16rpx。
- 固定底栏必须包含 `env(safe-area-inset-bottom)`，正文预留同等高度，不遮挡最后一项。
- 手机页面禁止横向滚动和嵌套滚动；长列表使用页面纵向滚动、分页或分批加载。

## 5. 形状、边界与层级

- 大卡片圆角 24rpx；输入框和普通按钮 18rpx；状态标签使用胶囊圆角。
- 常规卡片使用 1rpx 边框；只在浮动底栏和弹层使用阴影。
- 阴影：卡片 `0 4rpx 16rpx rgba(15,23,42,.06)`；弹层 `0 20rpx 60rpx rgba(15,23,42,.18)`。
- 不给每个元素都加阴影；同一层级的卡片保持相同高度逻辑和边界样式。

## 6. 导航与图标

- 底部只保留三个一级入口：计划、材料、成品。
- 每个入口使用同一套线性 SVG 图标并带文字；激活态同时改变颜色、字重和顶部短指示条。
- 二级页面使用微信原生导航返回；返回后保留上次筛选条件、列表位置和未提交表单草稿。
- 图标统一 2px 描边、圆角端点；不使用 Emoji、文字字符或不同风格图标混搭。
- 页面右上角最多放一个高频次级操作；其他操作进入“更多”菜单或页面内容区。

## 7. 通用组件

### 7.1 顶部状态条

- 标题下显示连接状态：`已连接 · 192.168…`、`连接中`、`连接失败`。
- 连接正常时低强调显示；失败时使用带文字的危险提示条并提供“重新连接”。

### 7.2 搜索与筛选

- 搜索框固定在页面主要内容顶部；筛选按钮显示已启用条件数量，如“筛选 3”。
- 常用第一条件直接展示，其他条件放入底部抽屉；钢板厚度永远是第一个条件。
- 已选条件显示可单独删除的筛选标签，并提供“清空全部”。
- 输入均有常驻字段名，placeholder 只作示例；数字字段调用数字/小数键盘。

### 7.3 数据卡片

- 第一行：业务主键（型号或规格）+ 状态。
- 第二行：材质、尺寸、库位等识别信息，使用两列键值布局。
- 第三行：库存数量或本次变动，用更大字号和单位展示。
- 底部：一个主要行操作和最多两个次级操作；点击卡片主体进入明细。
- 纸材卡片必须同时显示类型和完整型号，不能只显示归一化尺寸。

### 7.4 表单

- 单列布局；字段标签常驻在输入框上方。
- 必填项显示 `*`，复杂字段提供一行帮助文字。
- 失焦时校验，错误紧邻字段，内容说明“原因 + 修正方法”。
- 有未保存内容时，返回或关闭弹层需要二次确认。
- 提交按钮固定在底部安全区上方；提交后立即禁用并显示“提交中…”。

### 7.5 反馈状态

- 首次加载超过 300ms 显示与实际卡片同尺寸的骨架屏。
- 空状态区分：暂无业务数据、筛选无结果、连接失败、服务错误。
- 成功使用轻提示和数据刷新；错误提示包含重试或修改入口。
- Toast 3–5 秒自动消失，不承担必须阅读的错误说明。

### 7.6 确认弹层

- 从底部进入，顶部明确写操作名称，如“确认纸材出库”。
- 逐行核对型号/规格、数量、单价、库位、客户/去向和操作人。
- 普通写操作：主按钮绿色；撤回或停用：主按钮红色并要求原因。
- 取消入口始终可见；点击遮罩不直接丢弃已填写内容。

## 8. 动效

- 按压反馈在 100ms 内出现；状态变化 160–220ms，弹层进入不超过 280ms。
- 仅动画 `transform` 和 `opacity`；不动画宽高，不阻塞点击。
- 动效只用于按压、展开、提交状态、页面层级变化；不做装饰性循环动画。
- 尊重系统减少动态效果设置，关闭非必要位移和缩放。

## 9. 数据图表

- 月度趋势使用折线图；入库/出库、材质或客户比较使用水平条形图。
- 图表上方先给出总量、环比等文字结论，图表下方保留可读数值列表。
- 不使用 3D、雷达、桑基图，也不因类别多而堆叠饼图。
- 图例、坐标、单位齐全；颜色外再使用标签或线型区分。

## 10. 性能和列表

- 列表默认每批 20 条；超过 50 条持续使用分页/虚拟化策略，不一次渲染全部节点。
- 搜索输入 300ms 防抖；筛选变更由用户点击“查看结果”统一触发，避免连续请求。
- 列表刷新时保留已有内容并显示顶部加载状态，避免整页闪烁和布局跳动。
- 所有提交使用 `client_request_id`，按钮锁定直至结果明确。

## 11. 交付检查

- [ ] 375px、常见安卓宽度及横屏无横向滚动或内容遮挡。
- [ ] 所有触控目标至少 88rpx，间隔至少 16rpx。
- [ ] 型号、尺寸、批次号和备注不会挤成竖排或不可读窄列。
- [ ] 每屏只有一个视觉主操作，危险操作与普通操作明显分开。
- [ ] 加载、空、错误、离线、禁用、提交中、成功状态齐全。
- [ ] 表单具有常驻标签、就近错误和正确数字键盘。
- [ ] 返回后筛选、滚动位置和草稿按规范保留。
- [ ] 图标来源一致，无 Emoji；颜色不作为唯一状态线索。
- [ ] 文本对比度达到 WCAG AA，支持系统字号放大后的换行。
- [ ] 固定底栏和提交栏均避让底部安全区。
